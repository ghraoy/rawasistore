# موقع متجر رواسي

**الرابط:** https://rawasistore.com

موقع الزبائن لمتجر رواسي. البيانات (`data/catalog.json` والصور) ينشرها تطبيق الإدارة تلقائياً من [ghraoy/rawasi](https://github.com/ghraoy/rawasi)، فلا تعدّلها يدوياً.

- `index.html` و `shop.css` و `shop.js`: الموقع.
- `data/`: الكتالوج والصور (من التطبيق).
- `CNAME`: الدومين.
